🧹 1회성 세션 흔적 초기화 (Disposable Reset)

원클릭으로 브라우저의 쿠키, 캐시, 세션 스토리지 흔적을 완전히 소거하여 새 브라우저 상태로 되돌립니다.

🔐 Windows Root CA 인증서 관리

Windows 개인 인증서 저장소에 내 로컬 CA를 신뢰 등록하면, 순수 프록시 소켓 단독 모드에서도 보안 경고 없이 모든 HTTPS 트래픽을 완벽하게 통제할 수 있습니다.

모든 크롬 확장 프로그램 100% 호환

이 브라우저는 크롬 웹스토어의 모든 확장 프로그램(uBlock Origin, 번역기, 비밀번호 관리자, 테마 등)을 순정 크롬과 동일하게 지원합니다.
